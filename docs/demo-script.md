# Video demo script (3–5 minutes)

Record the browser and narrate this sequence. Use the seeded development account only in the demo environment.

1. **Context (20 sec):** “ACME has 10,000 employees. This replaces fragmented spreadsheets with a searchable employee and salary source of truth.”
2. **Dashboard (40 sec):** Show headcount, active count, country distribution and payroll totals grouped by currency. Explicitly call out that unlike currencies are not summed.
3. **Directory (60 sec):** Search for `EMP10000`; filter by country/department/status; move between pages. Point out that pagination is server-side.
4. **Profile/history (40 sec):** Open an employee, inspect compensation history and effective dates.
5. **Salary change (50 sec):** Add a salary amount/currency/effective date. Show the old period ending the day before and the new period beginning on its effective date.
6. **Employee management (30 sec):** Create an employee with an opening salary or edit profile details.
7. **Close (20 sec):** Mention API authentication, tests, deterministic seed, and explicit exclusions (tax/net pay, FX conversion and payroll execution).

Before recording, prepare the deployed URL and ensure seeded data and demo credentials are working. The video itself must be recorded by the submitter; no recording file is fabricated by this project.
